# 学习记录

这里保存课程进度、问过的问题，以及脱敏后的会话记录和原始底稿。`raw/` 保留课程内容与勘误的来源；未脱敏原文与映射表只留在本地 `private/`。

| 位置 | 内容 | 进 git |
|---|---|---|
| [progress-review.md](progress-review.md) | **进度总览**：课程怎么开始的、时间线、各章回顾、你的作答记录、下一步 | ✓ |
| [questions.md](questions.md) | **追问索引**：你问过的每个问题，写原话和结论，并链到答案 | ✓ |
| [sessions/](sessions/) | **会话记录**：按天整理，内部名称、设备标识和本地路径已替换 | ✓ |
| [raw/](raw/) | **脱敏原始底稿**：保留事件顺序、序号、时间和工具调用关系 | ✓ |
| [tools/import_session.py](tools/import_session.py) | 导入恢复出来的会话：脱敏 → 切分 → 生成逐字记录 → 自检 | ✓ |
| `private/` | 未脱敏的原文和脱敏映射表 | ✗ 只在本地 |

UUID、账号与会话标识替换为一致的匿名编号，同一标识在事件流和可读版中使用同一个编号。本机路径、邮箱、私有 IP 和内部项目名称也做脱敏。签名与截图等不透明 base64 数据保留字段和脱敏说明，不公开原始字节；因此这些记录用于追溯事实，不能直接重放原始工具调用。

## 怎么继续

新开会话时说一句「读一下 CLAUDE.md，继续学习」就能接上。
Claude Code 会自动读 `CLAUDE.md`；在 Cowork 里，明确说出这句更稳。
