公开版保留事件顺序、序号、时间和工具调用关联。内部名称按本地映射表替换；UUID、账号与会话标识使用一致的匿名编号，本机路径、邮箱、私有 IP 同样匿名化。重复的标识在同一份导出中使用同一个编号，便于追踪调用与结果。

签名、环境元数据、其他项目的目录列表，以及截图等不透明 base64 数据使用脱敏占位符。公开版可用于追溯事实，不能直接重放原始工具调用。未脱敏原文和映射表只在 `notes/private/`，不进入 git。

重新导入时使用 `notes/tools/import_session.py`；提交前运行 `python3 notes/tools/check_redaction.py`，同时检查 `raw/` 和 `sessions/`。
